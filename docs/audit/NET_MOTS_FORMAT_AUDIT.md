# MotS JKL preservation in the .NET editor

The starting C# fork discarded MotS's independent monochrome surface-light component, wrote only one channel per corner, dropped the architectural-lighting thing index, and left architectural data outside its model. The .NET format changes preserve those fields as structured data while keeping unchanged source sections intact.

## Implemented behavior

- `Surface.Corner.Intensity` remains the existing RGB interface. Nullable `MonoIntensity` holds the separate MotS monochrome value; null means derive the scalar value from the existing red channel for newly authored scalar corners. MotS output writes mono/R/G/B in engine order. Surface row cardinalities and finite light values are validated before indexing.
- `Level.ArchitecturalLighting` owns objects, meshes and double-precision mono/R/G/B vertex records. `Thing.ArchLightingIndex` defaults to `-1` and remains attached to the thing when its order changes. Counts are bounded by actual available section rows, record indexes must be sequential, malformed numbers are rejected, and `ARCHLIGHTING` requires its own `END`.
- Import records the resolved source model name. Saving refuses an architectural binding whose resolved model name has changed or whose object index is invalid. This is **not** a model-content hash or topology check: replacing a same-name model file remains outside the format reader's knowledge. Moving an object retains its original baked data and does not rebake it.
- Sector thrust, explicit collision bounds and authored bound box/center/radius are retained. Authored spatial bounds are reused only while the vertex-position baseline is unchanged; otherwise geometric bounds are recomputed. Spare sector vertices are retained. Distinct coincident source vertices are no longer merged, and the old 1e-4 pooling quantization is removed.
- The declared `World things` capacity is retained separately from the number of placed things, preserving room for runtime-created entities when a placed thing is edited.
- Layer comment names and memberships are parsed and rewritten consistently. Unknown membership references and count mismatches fail clearly.
- Material names are reconciled against the document's original material table. New names append without changing existing indexes; original rows retain their other material fields. A surface material-name edit is therefore reflected in saved geometry.
- Ordered `Thing.SourceParameters` and `Template.SourceParameters` preserve repeated keys, including every `frame=` entry, and parenthesized values containing spaces. The existing `Values` dictionaries remain the effective-value editing interface. Ordinary single-key edits merge with the ordered source records. Replacing an ambiguous repeated key through one dictionary value is refused instead of silently deleting the other records.
- A narrow legacy exception accepts a final `frame=(x/y/z:p/y/r` token containing six finite float values without its closing parenthesis, retains its spelling, and reports a preservation warning. The recovered Imperial Siege On Derra IV community level contains this form. OpenJKDF2 `sithTrackThing.c` accepts it because its six successful `sscanf` conversions precede the missing trailing literal. Other unmatched parameters, missing components, nonfinite values and appended parameters remain rejected.
- A separate TODOA compatibility rule accepts `eyeoffset=(x/y/z` only with three complete finite float components and no internal whitespace, nesting or suffix junk. It can end the line or precede another `key=value`. The original spelling is retained with a warning, and following `cog=` remains a separate parameter. This follows OpenJKDF2's whitespace tokenization in `stdConffile.c` and three-conversion check in `sithActor.c`; other malformed vector names are not accepted by this exception.
- `JklDocument` records a canonical representation of modeled sections at import. If the model representation has not changed, the writer keeps the original section text, including unknown content and comments. An edited HEADER or SECTORS section containing an unknown source field is refused, with details in `PreservationWarnings`. Unrecognized whole sections are retained. Regenerating Infernal Machine geometry is refused; this pass targets JK/MotS.
- Parsing builds a new model before returning it. Saving builds the complete output before writing a temporary sibling file and replacing the destination. Numeric parsing reports invalid values rather than silently substituting zero; count caps and required-row boundaries prevent unbounded truncated-input loops in the changed geometry paths.

## Executed evidence

The focused regression source is `dotnet/tests/Sed.Core.Tests/JklMotsPreservationTests.cs`. It exercises independent mono/RGB, architecture objects and bindings, changed-model refusal, engine capacity, unassigned sectors, authored collision/spatial fields, layer rewriting, material append, coincident vertex identities, malformed input, unchanged unknown source retention, repeated thing/template parameters and deep architectural copies. The earlier format checkpoint passed **28 JKL tests and 16 native-project tests**, with zero failures or skips. Later TODOA, editing and agent regressions passed together in a 70-test checkpoint. Aggregate suite results are tracked separately by the release validation work; overlapping checkpoints must not be added.

`dotnet/tools/Sed.MotsFormatAudit` reads the user's original game archives without extraction, editing or launching anything. [The native .NET corpus receipt](net_mots_format_evidence.json) records archive and per-level hashes, format/verifier assembly hashes, and per-level outcomes:

- **39 playable stock MotS levels:** full parse and no-edit output preserved every source line after newline normalization.
- **39 forced modeled-section regenerations:** all explicitly compared modeled semantics matched after reparsing, including ordered repeated parameters, surface component values, topology/positions, flags, authored sector bounds, thing capacity/bindings, templates and COG values.
- **2,353 architectural bindings and 38,622 architectural vertices** were retained. Each vertex contains four independent components.
- Source inspection found **653 thing rows and 153 template rows with repeated parameter keys**. The ordered-record fix prevents their earlier entries being lost when their section is rewritten.
- The forced comparison initially exposed an additional defect in `mdm07_vaporator.jkl`: distinct coincident vertices collapsed during pooling. Source identity now governs pooling, and a synthetic regression covers it.

The verifier excludes editor-generated IDs and rewritten global pooling indexes from its semantic digest. It includes the modeled field list explicitly in its source. Raw-source equality alone would not establish parser fidelity; the forced regeneration checks are separate evidence, and still cannot discover an original field that neither the model nor that comparison represents.

## Remaining limits

These results are **not an engine-load, editor-interaction, render, campaign, multiplayer or complete arbitrary-file preservation certificate**. No game was launched. Unknown whole sections can contain indexes that need remapping after topology edits; the writer currently retains those sections rather than interpreting every external reference. Known-section unsupported fields beyond the HEADER/SECTORS guards may still need dedicated models and validation. Architectural preview/rebaking and same-name model-content/topology verification require a resource-aware workflow beyond this pure format layer. Native JED/SED/NED project import has separate [source-derived coverage and limits](NET_NATIVE_JED_IMPORT.md).

Unchanged document preservation is text preservation after newline normalization, not a claim of byte-identical encoding or line endings. The import path still has legacy format assumptions outside the hardened paths. Retain source projects and evaluate edited exports with the intended engine before adopting a production workflow.

No licensed game payloads are included in the source, synthetic fixtures or evidence report.
