# SED MotS 0.4.0-mots.17-dev

This preview strengthens PLAY-01's automated gameplay acceptance. The original
four-room mission exercises activating a moving gate, traversing its open
passage, entering an objective and reaching an exit. Agents author the fixture
through the same CLI/MCP domain operations as the Windows editor.

The corrected evaluator requires goal0's sampled values to change exactly from
1 to3 in the same adjacent observation pair as the objective phase transition,
with its COG dispatch inside that pair's wall-time bracket. It rejects delayed
completion, reversion and fractional values that could previously produce a
false success. Generic telemetry still supports legitimate numeric inventory
values; this stricter rule belongs to the original test mission.

Lilitari's focused source review closed the goal-causality finding. Independent
local verification reproduced her235 transition-boundary probes and472
single-sample corruptions, accepted1.0/3.0 and preserved all seven historical
capture classifications. Source review and offline replay are distinct from
new packaged runtime acceptance.

This source snapshot is being prepared for release. Final package hashes,
fresh runtime results and publication receipts will be recorded in a follow-up
documentation commit and the release entry; they are not known at source freeze.
The optional native companion remains pinned to candidate04 / native commit
`d18ecc2a931586d5e57237cb0d301c9d07b89336`; a new editor package does not imply
a new native build. The original example excludes retail game content.

The scope is bounded single-player MotS behavior with recorded observations.
No retail parity, multiplayer/campaign acceptance, complete rendering parity,
unobserved persistence, exact assignment timing or resource-open telemetry is
claimed. Existing updater, research skill and workbench capabilities from .16
remain available. Raw community captures remain outside public artifacts.
