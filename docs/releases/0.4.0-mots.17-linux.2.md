# SED MotS 0.4.0-mots.17-linux.2

This native Linux increment adds reviewed dependency packaging to the existing
human editor, CLI and local MCP distribution. It builds on the completed
`0.4.0-mots.17-linux.1` port; the new authoring workflow requires no display,
graphics device, model service or game installation.

## Added

- Shared bounded dependency readers for 3DO materials, PUP keyframes, SND sounds,
  SPR/PAR materials, and typed COG declarations and placed values.
- Retained standard JKL resource-table roots, conservative template coverage,
  provenance, exact source receipts, explicit stock omissions, and visible
  incomplete/unsupported states.
- Deterministic one-level GOB/GOO planning with original JKL/resource bytes,
  strict archive names, sorted entries and exact readback.
- `schema package`, `package-plan`, and `package-apply`; matching
  `sed_package_plan` and `sed_package_apply` bring MCP discovery to thirteen tools.
- Separate output and manifest review hashes. Both are mandatory even when a
  changed stock role or unused source leaves output bytes identical.
- Fresh-source checks, atomic create-only publication, bounded responses before
  journaling, and reconnect recovery using the existing MCP operation ID.

The [packaging guide](../RESOURCE_PACKAGING.md) includes a complete human CLI
example and the MCP contract. The first increment takes saved JKL files and
explicit archives; native conversion remains a separate reviewed operation.

## Correctness fixes found during review

Resource lookup cache keys now preserve the folder/name boundary. Known null
sound/soundclass/parent sentinels use case-insensitive comparison. The package
planner refuses destination aliases that change lookup meaning, unsafe names,
missing or ambiguous resources, malformed supported records, duplicate template
declarations, repeated resource-valued parameters, and source/model lexical
differences. Unsupported lexical forms cannot downgrade known structural errors
to an acknowledgeable warning. A complete normalized COG schema continues to
check placed values even when a separate default is unsupported.

## Validation and release evidence

Development validation passed 1,801 Core and 293 MCP tests using original
fixtures. The native package gate repeats clean-source tests and headless UI
checks. Relocated verification includes independent Python GOB encoding/readback,
real CLI and MCP processes, dual-hash refusals, unchanged-input/no-overwrite
controls, and reconnect replay after the source archives disappear. The gate
preserves exact requests, streams and hashes in its generated evidence.

Consult the distribution's `PROVENANCE.json`, `SHA256SUMS.txt`, build receipt,
package receipt and verification report for its exact source commit and actual
executed results. These notes do not assert a remote CI result or an interactive
desktop/gameplay session. Linux installation remains portable; the existing
automatic updater is Windows-only.

## Limits

`runtimeClosureVerified` remains false. COG code, AI variants, engine fallbacks,
asset validity, rendering and gameplay require separate evidence. Stock
classification is caller-declared and must match the intended runtime baseline.
No Holocron code, engine binary or game assets are added. No new GUI packaging
dialog, arbitrary loose-file inclusion or in-place archive update is included.
